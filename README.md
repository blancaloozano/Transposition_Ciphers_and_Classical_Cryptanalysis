# Transposition_Ciphers_and_Classical_Cryptanalysis

This practice forms part of the subject Cryptography for Bachelor in Data Science and Engineering, CEU San Pablo University 2026/27. It mathematically implements classic transposition ciphers (railfence,columnar transposition and double columnar transposition) and the measurements used to identify a ciphertext (Kasiski, index of coincidence)

## 1. How to run everything

All commands assume you are in the repository root, with Python 3.11+ and only the standard library (pytest is needed only to run the tests).
